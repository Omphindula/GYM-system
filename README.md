# 🏋️‍♂️ Next-Gen Fitness Hub – Ump Gym Website

An interactive and dynamic website built for **Ump Gym**, designed to boost engagement, showcase gym services, manage memberships, and build a strong fitness community.

## 🌟 Features

- 🧑‍💻 User registration & login system  
- 💳 Membership & subscription management (with Stripe integration)  
- 📅 Booking system for classes and personal training  
- 📊 Real-time statistics and gym activity updates  
- 📂 Media sharing: videos, podcasts, events, and images  
- 📬 Contact and feedback forms  
- 🎨 Responsive, modern UI using HTML, CSS, Tailwind, and JavaScript  
- 🔐 Secure backend with PHP (Xapp) and MySQL
